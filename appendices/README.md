# Appendices

## Naming

Appendix notebooks use the format `Appendix_X_Name.ipynb` and are stored under `appendices/`.

## Usage

- Use Google Colab for execution and review.
- Run cells sequentially.
- No committed outputs are required for notebook shipping.
- The repository license applies to all appendix notebooks.
