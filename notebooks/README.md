# Notebooks

## Naming

Primary chapter notebooks use the format `ChNN_Title.ipynb` and are stored at the repository root under `notebooks/`.

## Usage

- Use Google Colab for the published links below.
- Run notebook cells in order from top to bottom.
- Generated outputs are not committed; keep notebooks in a clean execution state.
- Follow the repository license for all usage and redistribution constraints.
- Chapter 05–13 example notebooks load small CSV files from local package datasets in `data/`.

## Available

All notebooks below are currently committed and normalized with Colab links and licensing text in the first markdown cell.

Current scope includes chapters 04 through 13 and 14 through 25, plus appendix materials.
