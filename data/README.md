# Data

No external data files are committed in this initial companion release.

## Policy

- Notebooks either generate synthetic data directly in-code or document external retrieval workflows where applicable.
- Only small, approved, redistributable datasets may be committed.
- Restricted, proprietary, confidential, private, or personal customer data are prohibited.
- Do not include API keys, secrets, or credentials.
- Third-party data must be added only with source, license, citation requirements, and preprocessing notes.
- Large files require an explicit approved distribution plan before committing.
