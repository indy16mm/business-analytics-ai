# Data

Some companion notebooks in Chapters 05–13 use small, approved dataset files that are committed under this repository for convenience.

## Included datasets

| Filename | Used by | Notes |
|---|---|---|
| `Bank customer.csv` | Ch10 (Tree-based models), Ch12 (Clustering) | Bank marketing sample used for classification/clustering examples |
| `Credit card fraud.csv` | Ch09 (KNN) | Kaggle credit card fraud dataset sample |
| `Customer churn.csv` | Ch05, Ch07 | Telecom customer churn dataset sample |
| `Housing price.csv` | Ch08, Ch10 | Housing price prediction sample |
| `Movie.csv` | Ch05 (Regression), Ch06 | Movie metadata/revenue sample |
| `Student performance.csv` | Ch11 | Student performance sample |
| `Wholesale customer.csv` | Ch12 | Wholesale customer segmentation sample |
| `Wine.csv` | Ch13 | Wine classification sample |

## Missing data files in this source bundle

- `Telecom customer.csv` (required by `Ch12_Clustering_Bank_Customer_K_Modes_K_Prototypes.ipynb`) is not present in the local source bundle as a CSV file.
- A source link remains available in the source notebook package:
  - Bank Marketing dataset: https://archive.ics.uci.edu/dataset/222/bank+marketing

## Policy

- Data files are intended for companion notebook execution and educational demonstration.
- Restricted, proprietary, confidential, private, or personal customer data are prohibited.
- Do not include API keys, secrets, or credentials.
- Third-party data is added only with clear source references and non-sensitive terms.
- Large files require explicit repository-owner approval before addition.
